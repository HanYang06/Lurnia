## 一、结论先写

1. **前几版画不出来，不是画得不好。** 五个候选同属一族（中心 + 环绕物），变量在画法不在想法；
   语义是事后贴的；而且整轮都在画"光"——一个 [../ui.md](../ui.md) §一 已经明文否掉的动机。
2. **更硬的一条：标识工作从来没有合同。** 路线图里没有品牌条目，`014` 是权限模型里的
   **Subject 标识**，不是品牌标识（§二 最后一条）。没有"设计关联文件"就没有"有设计"的凭据，
   于是它只能靠审美验收——而审美单独不收敛。
3. **现在状态是干净的**：路线图无品牌条目、`app/src-tauri/icons/` 为空、`docs/design/assets/` 已删，
   零资产。零资产正好可以从叙事重来，不必背历史包袱。
4. 文字层要定的就五样：**一句话定位 / 一个可下判决的取舍 / 三条互斥的叙事向量 /
   一张"要·不要"矩阵 / 三条用文字描述到能画的候选**。本文给这五样，
   末尾（§4.8）标出只有项目所有者能裁的两处。

### 3.2 归纳出的启发式

1. **动笔前必须有一句能被追问的话。** 所有收敛了的案例都有（挑战清单、"belong anywhere"、"四种设备上连贯"、"区别于竞品"）；
   Gap 只有"更当代"，于是失败。**【跨案例归纳】**
2. **标识的首要功能是识别，不是传达。** Bierut 说得最直白：
   "我越来越不觉得新颖或聪明是好设计的核心属性……你可以说把一家电脑公司叫 Apple 很有意思，
   但这家公司的 logo 是一颗苹果的图案，那不叫聪明，**那叫字面到令人发闷**。"
   这条直接判掉 §4.2 的"Lurnia = 光"：**那是同一个错误的另一种语言版本**。
3. **必须在真实尺寸、真实语境下成立。** Google 测不同尺寸与场景的清晰度，Mastercard 要求广告牌与手表屏同样成立。
4. **用"别人记得什么"筛选保留项。** Instagram 的 5 秒记忆测试；Tropicana 的反面证据（-20%）。
5. **系统 > 单一图形。** Google 的成品是字体+圆点+网格+生成流水线；Stripe 的产品标识被做成共享视觉语言（[Landscape](https://thisislandscape.com/projects/stripe-product-logos/)）。
6. **独特资产比 logo 本身更重要。** 品牌被认出来靠一组可复用的独特资产，资产的价值在于**被记住**，不在于新颖（[Ehrenberg-Bass](https://marketingscience.info/news-and-insights/brands-need-distinctive-assets)）。
7. **一致性 ≠ 区别性。** Microsoft 赢在家族一致，代价是"大多数人不会知道它换过"。生态需要统一时选一致性，竞争白热化时选区别性。
8. **把"简洁"翻译成可测量的指标。** 14000 → 305 字节这种指标，让设计决策变得可争论、可验收【报】。

### 3.3 这些启发式互相冲突的地方（不粉饰）

- **MAYA（别太超前）与"拒绝安全解"直接相反。** 真实的分界不在激进/保守，而在**分层**：
  **mark 本身应该保守，叙事应该激进。** Airbnb 图形被嘲笑但叙事被记住；Gap 是叙事空洞、图形也平庸。
- **"必须能降维"与"独特资产"冲突。** 压到极小尺寸往往正好要删掉被记住的细节。
  Instagram 是例外——彩虹与镜头**同时**是细节和记忆点，代价是它不再是相机图案。
- **"记忆测试"与"系统一致性"冲突。** 用公司内部人的记忆做测试，天然偏向保守（他们记得的是**旧**图标）。
- **众包既是解药也是毒药。** 它能放大叙事，但 Gap 证明了**它不是决策方法**：把身份决策交出去，等于承认自己没有主张。
- **"被嘲讽"本身不是失败信号。** Airbnb 与 Instagram 都被大规模嘲讽，且都活了下来；
  Tropicana 有可量化损失（-20%），Gap 四天撤回。判别标准是**批评指向什么**：
  指向"被记住的叙事 / 记忆点被移除"→ 危险；只指向"新形态不习惯"→ 可承受。
  下一轮标识出来之后，这条比任何"好不好看"的讨论都更有用。

### 3.4 对本项目最直接的四条

1. **否定句不能生成形态。** "user-freedom-first / 无强制流程"约束的是**行为**，不是**形体**——
   单靠它，形态只能靠风格偏好来选，而这正是 §二 诊断出的病。它必须配一个**肯定句**，
   也就是 §4.1 那句"能装下很多东西、但从不向你要东西"。
   （`nothing more and nothing less` 是唯一已经含形态约束的现成句子：减法、单件、不膨胀。）
2. **生造词只有三条已验证路径，没有第四条"画个隐喻"的捷径**：
   **字形派生**（Google 的 Product Sans）· **符号化一个可输入字符**（Vercel 的品牌规范明确写
   symbol 只用在放不下完整 logo 处，并给出 `▲ U+25B2` 作为纯文本替代，[来源](https://vercel.com/geist/brands)）·
   **从一条约束里取形**（Linear 的品牌来自"一次一件事、一次一个维度"，
   连改版都是几百个屏幕收敛到几个方向，[来源](https://sspai.com/post/104449)）。
   §4.2 关闭"光"这条路之后，留给 Lurnia 的正是这三条。
3. **尺寸现实主义：主战场是 16–32px 的窗口/托盘图标，不是落地页 hero。**
   本项目是桌面 APP，"识别"发生在任务栏和安装包里，不是在大图上。
4. **小团队用约束系统替代人力。** 与其反复精修一个插画，不如把标识定义成
   一个约束系统（网格 + 字体派生 + 一个可输入符号 + 一组 token），让派生版本自动成立。
   §4.6 的三条候选之所以只写到"构造一句话"，就是为了把它们做成这样的系统而不是作品。


## 四、Lurnia 的叙事层

### 4.1 一句话（不可谈判的那句）

> **"一个能装下很多东西、但从不向你要东西的 APP。"**

前半句是能力池：笔记、项目、权限、协作、AI 都在，且**每条独立可发布**
（[../../roadmap/1.x-开发.md](../../roadmap/1.x-开发.md) 的路线增量）。
后半句是 [../invariants.md](../invariants.md) 的 I9 与"无强制流程"：
不开浏览器、不起服务、不联网、不注册、不催你、不需要你侍候它。

两个半句**互相拉扯**，这才是可写的叙事：**容量与克制同体**。
（[AGENTS.md](../../../AGENTS.md) §2 的 "a free platform — nothing more and nothing less"
说的是性质；上面这句说的是**对用户的承诺**。叙事要的是后者。）

**这句话能下判决，所以它有用**：凡是"向你要东西"的形态一律出局——
强中心的辐射/星形（你得围着它转）、锁与盾（把用户关在外面）、
上升箭头与仪表盘（暗示你该成长、该更高效）、齿轮（暗示你该配置它）。

### 4.2 名字怎么处理

**名字不是叙事。** `Lurnia` 是生造词，没有可画的所指——和 Vercel / Notion / Linear 一样，
它只提供**声音与字形**，不提供图形。所以先定读音与写法，图形另行处理：

| 项 | 定稿 | 理由 |
| --- | --- | --- |
| 读音 | **LUR-ni-a**（三音节，重音在第一音节） | 先定读音，字形服从读音；三音节决定了字标不能挤成两段 |
| 写法 | 正文与界面一律 `Lurnia`（仅首字母大写） | 生造词全小写损失起手识别；全大写在小字号下变成色块 |
| `LURNIA` | 只允许用于极窄场合（版权行、许可证头） | — |
| 中文名 | **暂不设** | 设了就要维护两套，且会诱导"意译图形" |

**"光"这条路，明确关闭。** 不是因为不好看，是三条同时成立：
（a）[../ui.md](../ui.md) §一 已经否过一次；（b）`lumen / lux / light / luc-` 是非独家联想，
一大批产品在用；（c）它把"叙事"偷换成"名字的谐音"，而这正是 §二 诊断出的病根。
名字的语源留给文案，不给图形。

### 4.3 三条互斥的叙事向量

**"互斥"是关键**——能互相判否的才是真候选，否则又会退化成同一个吸引子。
每条标出：从哪来（必须是**项目内部事实**）/ 它下什么判决 / 它自带什么风险。

#### 向量 A · 承载：东西放进去，它不碰

- **来源**：能力池（一个 APP，多种能力）；[../storage.md](../storage.md) 的双库 + 附件库
- **判决**：排除一切强调"处理 / 流转 / 智能"的形态（箭头、循环、节点网）
- **风险**：容易滑向"容器"俗套（盒、环、杯）——**即上一轮的候选 A**

#### 向量 B · 来处：每一次变化都有来源，且可回退 ← **本文件推荐**

- **来源**：I5（先写事件日志，后落数据）、I4（`version` + `migrate()`）、
  版本 `0.x` 不承诺终点、路线图"版本是落点不是顺序"，
  以及 [../ui.md](../ui.md) §3.2 **已把"日志脊柱"定为签名元素**
- **判决**：排除"瞬时 / 魔法 / 自动完成"的表达。本项目最硬的事实是**可解释**
- **为什么它最强**：它是唯一一个**已经存在于产品自己设计语言里**的东西。
  "日志脊柱"已被 ui.md 称为签名元素，却从没被用在标识上——
  而它**不可从名字推导**，所以也不会被同名产品撞上
- **风险**：时间轴/竖线本身也是常见形状。区别性必须来自**脊柱的具体构造**
  （版本节点、最新在上、可滚动），不能来自"一根线"

#### 向量 C · 私有：东西在你这台机器上，不经过别人

- **来源**：I9 全条、local-first、"双击就能用"
- **判决**：排除云、同步、账号、网络的一切视觉语汇
- **风险**：**最高**。锁、盾、划断的网线、"本地"标签全是俗套；
  而且"私有"是**否定式**主张，很难画成肯定式图形

> **建议**：以 **B 为主干、A 为次要性格**（B 给"可解释"，A 给"容纳且不干涉"）；
> **C 只作为文案**（"数据在你自己机器上"），不进入图形。
> 理由是 B 的区别性来自项目内部事实，这是唯一不可被别家抄走的来源。

#### 4.3.1 每条向量对应的一句"用户话"

"表达的角度"最终要落在**用户会怎么复述它**。这一栏是图形之前的最后一个文字关口：
如果这条向量找不出一句自然的、非广告腔的句子，它就不该被画。

| 向量 | 用户会说的一句话 | 失效表现（说出来就假） |
| --- | --- | --- |
| A 承载 | "东西都在里面，它不催我。" | "帮你把一切连接起来"（那是别人的话） |
| **B 来处** | **"改了什么、什么时候改的，都还在。"** | "让知识自然生长"（抒情，不可判否） |
| C 私有 | "这些东西在我自己的电脑上。" | "守护你的数据主权"（法务腔） |

注意三条**都是陈述句**，没有一条是祈使句或承诺句。这不是巧合——见下。

#### 4.3.2 品牌声音：只说陈述句

`nothing more and nothing less` 已经给出了语气：**陈述，不劝服**。

| 要 | 不要 |
| --- | --- |
| 陈述句："数据在你机器上" | 祈使句："开始你的知识之旅" |
| 不承诺路线图之外的事 | 感叹号、emoji、"AI 加持" |
| 允许说"这还不支持" | 用将来时兜售（"即将支持…"） |
| 短句，主语是用户的东西 | 主语是 Lurnia（"Lurnia 帮你…"） |

**这与图形直接相关**：一个只说陈述句的品牌，它的标识应该是**陈述**（一个静止的、可读的事实），
而不是**承诺**（向上的箭头、发光的球、动起来的循环）。
凡是"看起来很进取"的形态，都与这套声音矛盾——这是 §4.5 反简报的又一条理由。

### 4.4 "要 / 不要"矩阵

判据是图形无关的，所以它可以先于任何画稿存在：

| 要 | 不要 | 判据 |
| --- | --- | --- |
| 一眼可描述（"一条竖着的刻度"） | 需要解释（"这代表三个模块协作"） | 说不出来 = 没有识别 |
| **一个**可命名的特征 | 一堆对称细节 | 16px 下只活得过一个特征 |
| 与工作界面同族的性格（安静、低饱和） | 品牌层随便炫技 | §1.1 允许品牌层"放开"，但放开 ≠ 变成另一个产品 |
| 单色成立 | 靠渐变/发光才成立 | 缩小测试与传真测试 |
| 能被说成一句**动词句** | 只能被说成名词 | 用户记住的是动词 |

### 4.5 反简报：明确不许出现

以下形态**不是"不好看"，是"非独家"**——它们已经属于品类，不属于 Lurnia：

发光球 / 光晕（AI orb 俗套）· 光圈 / 快门 / 叶片（上一轮 B·F，且撞 Aperture、Loom）·
三弧 + 圆心（撞 Blender）· 云 · 锁 · 盾 · 齿轮 · 书本 · 大脑 / 神经网 · 无穷符号 ·
节点图 + 连线 · 上升箭头 · 仪表盘 · 彩虹渐变 · 任何"必须先加发光才成立"的形态。

### 4.6 三条候选：用文字描述到可以画

这一节的作用是**证明文字层能约束到可画**，不是图形稿。
每条只写到"构造一句话"，几何参数等向量裁定后再做。

| # | 一句话 | 构造（文字，非图形） | 缩小预判 |
| --- | --- | --- | --- |
| **一**（B 主干） | 一条刻度 | 一根竖线，串若干**等距短横**；最新的一端更实，另一端渐隐 | 16px 下活下"刻度"这一个特征 |
| **二**（A+B） | 开口的容器 | 一个**不闭合**的轮廓（开口朝上），内部 2–3 条**不等长**横线 | 开口是主要识别特征，缩小时不能丢 |
| **三**（B 极简） | 两个版本 | 点 — 竖线 — 点：版本时间轴被抽到只剩两个版本 | 最耐缩小，但需自查是否读成冒号/省略号 |

三条都**没有**用到"光"，也都**不可从名字推导**——这是对 §4.2 与 §4.3 的验收。

### 4.7 验收：把文字变成可判否

| # | 测试 | 通过条件 |
| --- | --- | --- |
| 1 | **描述测试** | 给 5 个人看 5 秒，请各用一句话说这是什么；≥4 人说出**同一个名词**，且该名词不是"光/球/环" |
| 2 | **缩小测试** | 缩到 16px、去色，仍有**一个**可命名的特征 |
| 3 | **相邻测试** | 放进 Windows 任务栏 / 桌面图标网格，不与系统图标或常见第三方图标混同 |
| 4 | **语境测试** | 放进真实的应用图标网格与启动页看（在真实界面里看效果，不是在白底上评审） |
| 5 | **反向测试** | 能用一句话说出它**不是**什么："它不表达智能，不表达云，不表达效率" |
| 6 | **撞车检查** | 逐条做形态近似排查并留档（沿用上一轮的表格做法，作为独立创作证据） |
| 7 | **复述测试（最硬）** | 半年后不看本文件，能否凭标识说出 §4.3 向量 B 那句话 |
| 8 | **形容词测试**（来自 Gap 2010） | 定位句里若只有形容词（"更安静""更自由""更当代"），它**生成不了形态**。句子里必须能读出名词或动作 |

## 五、产出与实测（2026-10-16）

**动物已定为水豚（capybara）。** 选它的理由不是可爱，是语义：
半身泡水这一形象天然对应"不催你、不需要你侍候它"（[../ui.md](../ui.md) §一 的性格主张），
而且**泡水姿势把腿和尾巴藏掉了**——正好是标记需要的"部件少、有平直基线"（§五.2 有实测）。

### 5.2 实测结论（这些是"为什么这么做"的依据）

| 结论 | 数据 |
| --- | --- |
| **半身泡水的剪影可用；全身姿势不可用** | 全身侧影 32px 起像河马/仓鼠；泡水姿势 32px 仍可辨 |
| **纯三角形抽象在标记层不成立** | 细 1568 三角形/74 色、中 392/25、粗 98/7——**粗档已不是水豚**。16×16=256px ÷ 98 = 每片 2.6px |
| **减色法会抹掉面结构** | 水色变灰、身上长斑；改为**按面缝分割**得 **39 个面**，水色保住 |
| **厚涂肌理进不了矢量** | 边界分形度 **57.9**（纯平涂 2.2）；边界占画面 23.11% |
| **自动追踪不划算** | 39 路径 / **4173 节点** / 52 KB；人工重画约 200 节点 = **1/20** |
| **22% 圆角的内容上限** | 94% 无溢出；96% 起切主体（849px @100%） |
| **图标底色与圆角** | 内容 82% → **88%**；深色任务栏上由受光面撑住形体 |
